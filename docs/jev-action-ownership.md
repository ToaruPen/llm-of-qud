# 行動と状況に応じた Claude / Jev の担当

2026-09-28。目的は、通常操作を Jev が継続し、危険の評価・方針変更・将来に影響する選択を Claude Opus に集めること。Jev の選択肢確率は死亡確率でも正答率でもないため、低い値だけで移譲する運用を通常操作には適用しない。

現在の実行 API が扱う行動を対象とする。射撃、変異能力の発動、変異ポイントの配分、取引は未対応であり、この分類によって実行可能になるわけではない。

| 行動 | 通常の担当 | Claude に戻す条件・境界 |
|---|---|---|
| 状態・地図・結果の取得 | 実行系 | 古い観測の選択は破棄。観測の欠落・不整合は修復対象 |
| 既知の空きマスへ1歩移動 | Jev | 低HP、危険な状態異常、未知の地形・占有、上位の移動制約との衝突、失敗・ループ |
| 既知の目的地への自動移動 | 承認済み計画を実行系が実行 | 敵・危険の出現、被害、進展なし、目的地到達後の次の目的の選択 |
| 自動探索 | 条件付きでJev | 安全な局所探索の承認範囲内。敵・危険・目的変更はClaude |
| エリア境界・階段・ワールドマップ移動 | 条件付き | 進路・探索方針はClaude。遷移後は新しい区域として確認 |
| 通常の近接攻撃 | 条件付きでJev | Claudeが交戦を認めた相手、十分なHP、単独の隣接敵、危険な状態異常なし。未評価の相手、包囲、急な損耗はClaude |
| 迂回・撤退 | 条件付きでJev | 承認された方向と危険距離の外で継続。遠方の敵の座標変化だけでは再計画しない。新種・増援・危険距離への侵入・被害で見直す |
| 待機・休息 | 条件付きでJev | 安全な回復は継続。毒、出血、炎上などの進行性異常や敵の接近はClaude。無意味な待機は進展検査の対象 |
| 食べる・飲む | 条件付き | 平常時の既知の食料・純水は日常操作になり得る。薬効、副作用、成分・用途の不明なものはClaude。既存観測で条件を確定できない候補もClaude |
| 薬・アーティファクトの使用、容器を開く | Claude | 有限資源、未知の作用、付随する選択を評価する |
| 拾う | 条件付き | 目的物・重量・危険な液体等の確認が必要。現在の観測だけで日常回収と認定できない候補はClaude |
| 会話開始、発言を聞き続ける・閉じる | 条件付きでJev | クエスト、物品引き渡し、その他の分岐選択はClaude。応答受理とクエスト達成は区別する |
| スキル・能力値・装備の変更 | Claude | 安全な機会にビルドとの相性、前提条件、将来の強化を評価。実行結果を観測してから方針を更新 |
| 目的・経路・クエスト方針の変更 | Claude | 目標到達、エリア変更、予定した経路の破綻、知識不足を含む |

危険度と操作の不確かさを分ける。同じ移動でも、平常時に空きマスへ進むことと、混乱中に液体の隣で敵へ近づくことは別扱いにする。状態異常・液体の組み合わせは [危険度の規則](jev-hazard-policy.md) と [分類表](jev-status-catalog.md) を使い、未知は未知のまま保持する。

危険局面を評価した上位は、`continuation` に短い実行手順を指定できる。`route` は現在位置の次から始まる隣接セル列、`hold_position` は1ターン待機を許可する位置、`attack_target` は単独の隣接敵への反復攻撃を許可する位置。未使用の位置はnull、経路は空配列とする。`max_steps` は1〜8手で、計画のhorizonも超えない。既知の混乱が続くことだけでは失効せず、待機を明示した位置では有効期間中の「進展なし」を抑制する。終了後は再評価する。

`min_hp` 以下、または最大HPの40%以下で上位に戻す。`max_damage` は計画発行以降の観測HP減少の合計で、回復しても相殺しない。最大HPの25%を超える累積被害、1操作で20%以上の減少も継続を止める。同一操作内の被害と回復は相殺されて観測されるため、実際の総被害量とは限らない。危険度4・未知の異常・異常の変化、新種や増援、敵の接近、移動失敗・経路逸脱、資源使用、期限切れも失効条件。退避中の攻撃禁止は維持する。各手は最新候補と照合し、低確率だけでは承認済み手順を上位へ戻さない。

被害と消耗品操作は出典付きの`risk_outcome`として既存の検証イベントに保持する（直近128イベント）。区域内の位置別集計`route_risks`を両モデルへ渡す。2回以上のHP減少を観測した操作終了位置への再進入は、上位の個別判断を要求する。これは実行位置から危険原因や射程を推定する規則ではない。自動移動中の途中経路も、この集計だけでは判定できない。上位には安全性の観測事実・推定・未確認を分け、HP回復だけを再挑戦の根拠とせず、経路断念や別目標への変更も判断するよう指示する。

書き手はClaudeの戦略応答とプレイヤーの計画保存。新規戦略応答では`continuation`またはnullを要求し、旧保存計画でフィールドがない場合は従来の移譲規則を使う。限定移動相談の応答を既存計画へ反映する際は古い承認を破棄する。復帰時も新しい上位評価を必須とし、古い危険対処の承認を再利用しない。

遠方の敵を見ただけで戦闘方針に切り替えない。現在の実装では `hostile_response=fight` が、移動中でも Jev 向けの目的地・指示を消す場合があり、Opus が意図した迂回と食い違っていた。交戦判断の距離を上位計画で指定し、その外では移動指示を維持する。距離は敵の射程を保証する値ではなく、上位モデルが設定する再評価の境界である。未知の敵や実際の被害は別途評価する。

移動可能な方向も、必要な場合は計画の構造化データにする。文章の「西へ行かない」だけに依存せず、該当する区域・計画の有効期間内で候補に反映する。地形や位置が変わって制約を満たせなくなったら上位に戻す。

実装では `tactics.danger_distance`（1〜40、旧計画の既定値6）と `allowed_directions`（8方位の部分集合、空配列は制限なし）を追加した。既存の保存計画は受理し、新しい上位応答のスキーマは両方を要求する。書き手はClaudeの戦略応答と、それを保持するプレイヤーの計画保存。限定的な移動相談は既存tacticsを保持するため、方向制約のある計画の更新は戦略相談に戻す。経路内部を検査できないgoto/exploreは方向制約中に候補へ出さない。

敵の再評価は公開された種類・数と距離帯で行う。遠方、危険距離内、隣接の境界を越えて近づくこと、新種や増援、回避中の被害で戻す。観測ごとに変わる敵IDは個体追跡に使わず、視界から消えた敵の死亡も推定しない。単独近接戦では通常の小さな損耗を許容するが、1操作で最大HPの20%以上を失った場合や回復閾値を下回る操作選択は再評価する。

確率による移譲は条件を確認できない選択に残す。日常操作では、分布の形式・候補ID・現状との一致を検証したうえで Jev の最上位候補を採用する。高確率でも危険・方針衝突・不可逆な判断を通さない。正規のゲーム結果を確認し、失敗や往復を次の判断へ反映する。

実装の検証には、敵が移動しただけの迂回、目的と逆向きの候補、遠方の敵と隣接敵、HP低下、状態異常の組み合わせ、ビルド変更、会話の分岐を使う。今回の実ログを固定入力として新旧を比較する。過去ログの再判定で分かるのは担当や入力の違いであり、別の行動を選んだ先の生存・到達を実証するものではない。
