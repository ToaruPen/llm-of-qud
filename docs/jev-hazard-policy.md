# 状態・液体の危険度と上位判断への移譲

2026-09-28。対象は固定版 2.0.211.56 / build 25520692。実装は `harness/hybrid_hazards.py`、観測は `mod/LlmOfQud/Observation.cs`。

同日のOBS試走後、[状態分類カタログ](jev-status-catalog.md) に拡張した。以下は初期ルールの背景であり、現在の追加分類はそちらを参照。wiki一覧78項目、液体27種類、トニック11種類を照合し、回復・疾病前兆・プラズマ・認識障害などを区別する。初期分類より範囲は広がったが、ゲーム内の全効果・相互作用の完全モデルではない。

状態名を一律に危険扱いすると、血やスライムの付着だけで計画を立て直してしまう。反対に、通常の状態名一覧だけを見ると、プレイヤーでは名前が省略される燃焼・凍結を見落とす。今回は公開観測を増やし、個別の効果と同時に成立する条件を分けて評価する。

危険度は死亡確率ではなく、判断の優先順位を表す手作業の尺度。0＝通常、1＝文脈次第、2＝注意、3＝急ぎの再判断、4＝緊急とする。加点を無制限に足さず、成立した規則の最大値を採用する。各規則には根拠となる観測と出典を添える。未知の効果は未知のまま残す。

| 観測・組み合わせ | 優先度 | 扱いと根拠 |
|---|---:|---|
| 血・塩・スライムなどの付着や乾いた染み | 1 | 付着だけで出血・転倒・感染とは判定しない。[Covered in liquid](https://wiki.cavesofqud.com/wiki/Covered_in_liquid) |
| 出血・毒・燃焼 | 3 | 継続ダメージ。毒では自然回復が止まり、回復効果も弱まる。[Bleeding](https://wiki.cavesofqud.com/wiki/Bleeding)、[Poisoned](https://wiki.cavesofqud.com/wiki/Poisoned)、[Burning](https://wiki.cavesofqud.com/wiki/Burning) |
| 継続ダメージ＋HP35%以下、または複数の継続ダメージ | 4 | 残りHPや重複を踏まえた運用上の優先度。35%はゲーム公式の閾値ではない。状態一覧の実際の重複を数え、繰り返し表示されたログは数えない。 |
| 凍結・拘束・伏せ等 | 2 | 移動や行動の制約。敵または継続ダメージが同時にあると4。[Frozen](https://wiki.cavesofqud.com/wiki/Frozen)、[Stuck](https://wiki.cavesofqud.com/wiki/Stuck)、[Prone](https://wiki.cavesofqud.com/wiki/Prone) |
| 酸・溶岩等の現在の付着 | 3 | 身体と装備を区別する。本人の耐性があっても装備の安全までは確定しない。容器や電池を携帯しているだけでは付着とみなさない。[Acid](https://wiki.cavesofqud.com/wiki/Acid)、[Lava](https://wiki.cavesofqud.com/wiki/Lava) |
| 有害液体が足元にあり、同時に伏せている（家具上の `lying on X` を含む） | 4 | Wikiでは黒い粘液の疾病、緑のgooの毒、茶色い汚泥の装備腐食が記載される。ただし感染成立そのものは次の状態観測で確認する。[Prone](https://wiki.cavesofqud.com/wiki/Prone)、[Black ooze](https://wiki.cavesofqud.com/wiki/Black_ooze)、[Brown sludge](https://wiki.cavesofqud.com/wiki/Brown_sludge) |
| スライム・油・タールなどの見えている地面の液体 | 1、敵がいれば2 | 移動への影響を文脈として渡す。付着と地面の液体は別。深さ・免疫が未確認なら転倒を断定しない。[Slime](https://wiki.cavesofqud.com/wiki/Slime)、[Oil](https://wiki.cavesofqud.com/wiki/Oil)、[Asphalt](https://wiki.cavesofqud.com/wiki/Asphalt) |
| 燃焼＋油・タールの付着 | 3 | 共存を明示するが、付着による追加着火・ダメージ増加は固定版で確認できず、燃焼単体より加点しない。乾いた染みを可燃液体の現在の付着と扱わない。 |

Wikiの油・スライムの転倒条件には古い版の数値が残る。酸の気化温度にも表と本文の不一致がある。これらの数値は実装に採用していない。Wiki本文は通常の公開HTTP取得で読み、取得記録を `.runtime/jev-hazards-20260928/research/` に保存した。検索ツールではrobots制限が出たため、検索スニペットだけで内容を確認した扱いにはしていない。

固定DLLでは `LiquidVolume.ProcessContact` が身体・装備への接触を配分し、伏せ状態で接触量が増えること、`LiquidAcid.SmearOn` / `SmearOnTick` が付着時・各ターンの酸ダメージを処理することを確認した。一方、油・タールの `SmearOnTick` は既定の空実装で、乾いた染みにも継続接触ダメージ処理はない。液体の燃焼温度と「付着で本人の着火条件が変わる」という主張を混同しない。

## 観測と責任分担

- `status.effect_details`：キャラクター画面で表示される状態名と説明。`on_fire` / `frozen` は公開される現在の燃焼・凍結状態を補う。
- `status.nearby_liquids`：現在地を含む3×3のうち、セルと開放液体オブジェクトの両方が可視のもの。地面の液体を容器の中身と混同しない。未探索領域や隠れた敵は読まない。
- `item_details.effect_details`：公開される効果名。装備の付着量など、通常の説明で非表示の値は出さない。
- `item_details.comparison_name`：未鑑定状態・性能数値・既知の修飾を保持し、明確に特定できる液体の付着接頭辞と個数を比較から除く。除去が曖昧なら元の名前を残す。元の名前と付着情報は戦術側に残す。
- 既存の観測を書いているのは本番の `Observation.cs` とテスト・プローブのフィクスチャ。追加フィールドは任意として旧形も受理し、保存済みledgerを読み続けられるようにする。

ClaudeとJevの両方に同じ危険評価を渡す。優先度3以上の新しい条件・悪化、または未知の効果を上位へ移譲する。同じ危険に対する上位判断は記録し、毎手の再計画は避ける。同じ危険かは規則・優先度・対象名で比べ、地面の液体だけは種類で比べる。見えているセル数や位置の増減だけでは変化とせず、種類の追加、足元への進入による優先度上昇、付着は変化とする。体や装備の付着など液体以外の一致項目は、これまでどおり1件ずつ数える。承認済み経路の残りのセルに新しい危険液体が見えた場合は `continuation_route_hazard` で再相談する。解消後の再発は再評価する。優先度2以上や未知の効果がある間は任意の成長・装備変更と移動・休息マクロを控える。個別の行動は公開候補から選び、Jevの選択確率0.5未満の移譲も維持する。

移動失敗は、実際に拒否された操作と、その時点の公開状態を対応づける。同じ位置・時間・周辺状態のまま、消費時間なしで塞がれた方向は候補から除く。時間や状態が変われば再び候補に戻す。戦闘の実行成功は命中を意味しないため、空振りを移動停滞とは扱わない。敵の位置・負傷表示と地図の更新も進展の比較に含める。

これは全効果の完全な戦術モデルではない。ガスの濃度、隠れた能力、未鑑定の耐性、全トニック相互作用、翻訳MODの別名までは網羅していない。未知の効果は上位へ伝え、未実装の洗浄・能力操作を実行できると装わない。固定版の待機操作には消火の試行・凍結時の温度上昇が含まれるが、成功は次の観測で確かめる。
